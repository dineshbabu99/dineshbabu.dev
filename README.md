## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/dineshbabu99/dineshbabu.dev.git
```

Navigate to the project:

```bash
cd dineshbabu.dev
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
